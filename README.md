# ✈️ Airline Management System

## 📌 Project Overview

The **Airline Management System** is an interactive frontend web application developed using **HTML, CSS, and JavaScript**. The system provides a user-friendly interface for searching flights, viewing flight information, selecting seats, choosing meals, and completing a booking process.

The project focuses on developing an attractive and interactive airline booking experience using core frontend web technologies.

## 🎯 Objectives

- Develop an interactive airline management web application.
- Provide flight search functionality.
- Display domestic and international flight details.
- Allow users to select available flights.
- Provide an interactive seat selection interface.
- Allow users to choose meal preferences.
- Provide a booking and payment interface.
- Create a responsive and user-friendly interface.

## ✨ Features

- 🔐 Login interface
- ✈️ Domestic flight search
- 🌍 International flight search
- 🔎 Flight search by source and destination
- 🕐 Flight timing and duration display
- 💰 Flight price display
- 🛫 Flight selection
- 💺 Interactive seat selection
- 🍴 Meal selection
- 🎫 Booking confirmation
- 💳 Payment interface
- 📱 Responsive user interface
- ⚡ JavaScript-based interactions

## 🛠️ Technologies Used

- **HTML5** – Structure of the web pages
- **CSS3** – Styling, layout, responsiveness, and UI design
- **JavaScript** – Dynamic functionality and user interactions
